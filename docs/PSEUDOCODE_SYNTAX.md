# UNNC AlgoLab 伪代码语法规则

这份文档描述**当前版本实际实现**的语法与运行行为，供检查和修改规则使用。示例中的 `...` 只是说明占位符，不是可直接输入的语法。编辑器的颜色提示不决定代码是否有效；语法检查以解释器为准。

## 1. 程序与算法声明

一个文件至少要有一个算法声明。每个算法从标题行开始，到下一个算法标题或文件结尾结束；算法本身不需要 `end`。同一文件中的算法名不能重复，调用时算法名区分大小写。

```text
Algorithm: Main(n)
  return Double(n)

Sub-Algorithm: Double(x)
  return x * 2
```

标题格式：

```text
Algorithm: 名称(参数1, 参数2)
Sub-Algorithm: 名称(参数1, 参数2)
SubAlgorithm: 名称(参数1, 参数2)
```

- `Algorithm`、`Sub-Algorithm`、`SubAlgorithm` 大小写不敏感；冒号和圆括号必需。无参数也要写 `()`。
- 名称和参数名以 Unicode 字母或 `_` 开头，后面可用 Unicode 字母、数字、`_`。例如 `求和_1` 有效，`1sum` 无效。
- 同一个算法的参数名不能重复，参数用英文逗号分隔。参数数量必须与调用时的实参数量一致。
- 可以在标题后、第一条语句前写任意数量的 `Require:`、`Requires:`、`Return:`、`Returns:` 说明行。它们不参与运行，也不会验证输入或返回值；放在语句之后就不再是说明行。

## 2. 行、注释与标点

- 一行写一条语句或一个块标记；空行与缩进不影响解析，缩进只用于阅读。
- 行尾可有一个 `;`。不能用分号在同一行连接多条语句。
- `#` 和 `//` 开始行注释；字符串内的这两个记号不算注释。
- 每行开头可带行号，例如 `1. return x`、`2: return x`、`3, return x`、`4· return x`。解析器也接受不带分隔符的行号，因此**不要让一条无行号语句直接以数字开头**，否则开头数字可能被当作行号移除。
- 解析前会把全角圆括号、冒号、分号、逗号、方括号及弯引号转换成对应英文字符，也会转换 `←` → `=`、`≤` → `<=`、`≥` → `>=`、`≠` → `!=`、`–` → `-`、`。` → `.`、`！` → `!`。这一替换对字符串内容也生效；需要保留原样标点时应注意这一点。

## 3. 语句

| 写法 | 行为 |
| --- | --- |
| `let name = 表达式` | 计算并设置变量。 |
| `name = 表达式` 或 `name ← 表达式` | 计算并设置变量；即使变量此前不存在也可使用。 |
| `return 表达式` | 立即结束当前算法并返回值；表达式必填。 |
| `print 表达式` 或 `print(表达式)` | 把格式化后的值添加到输出区；表达式必填。 |
| `表达式` | 计算表达式并丢弃结果，常用于单独调用算法。 |

`let` 和普通赋值在当前实现中都是向当前算法的变量环境写值，没有单独的声明检查。被调用算法有自己的变量环境。语句关键字如 `let`、`return`、`print` 不区分大小写；变量名区分大小写。

### 条件分支

```text
if n < 0 then
  return -1
elseif n == 0
  return 0
else if n == 1 do
  return 1
else
  return 2
endif
```

- `if 条件` 后可选写 `then` 或 `do`。
- 可写任意多个 `elseif 条件` 或 `else if 条件`，再可选写一个 `else`。
- 用 `endif` 或 `end if` 结束；这些关键字不区分大小写。
- 条件按下文“真假规则”判断；只执行第一个条件成立的分支。

### 循环

```text
while n > 0 do
  n = n - 1
endwhile
```

`while 条件` 后可选写 `then` 或 `do`；用 `endwhile` 或 `end while` 结束。每轮开始时重新计算条件。`if`、`while` 可以嵌套，但各自必须闭合。当前没有 `for`、`break`、`continue`。

## 4. 表达式与值

| 类别 | 支持的写法 | 说明 |
| --- | --- | --- |
| 数字 | `0`、`12`、`3.14` | 十进制整数或小数；负数由一元 `-` 构成。没有指数写法。 |
| 字符串 | `'text'`、`"text"` | 支持 `\n`、`\r`、`\t`、`\\`、`\'`、`\"` 转义。 |
| 布尔值 | `true`、`false` | 不区分大小写。 |
| 列表 | `[]`、`[1, 2, 3]` | 元素可以是任意支持的值，包括嵌套列表。 |
| 特殊名称 | `nil`、`leaf` | `nil` 每次求值产生空列表 `[]`；`leaf` 是树叶值。均不区分大小写。 |
| 变量 | `score`、`求和_1` | 必须在当前算法中已有值，否则运行时报错。 |
| 调用 | `F(10)`、`cons(1, nil)` | 只能调用有名称的算法或内置函数；不能调用任意表达式。 |
| 分组 | `(a + b) * 2` | 用圆括号控制优先级。 |

**当前没有 `null` 字面量。** 算法执行到末尾没有 `return` 时返回 `null`；`value([])` 也返回 `null`。`nil` 是空列表，不是 `null`。

### 运算符优先级

从高到低排列；同一级二元运算符按从左到右结合。`not`、一元 `+`、一元 `-` 作用于紧随其后的表达式。

| 优先级 | 运算符 | 行为 |
| --- | --- | --- |
| 1，最高 | `not`、一元 `+`、一元 `-` | 逻辑取反、数字正负号。 |
| 2 | `*`、`/`、`mod`、`%` | 数字乘、除、取余；`%` 等同 `mod`。 |
| 3 | `+`、`-` | 加、减。 |
| 4 | `==`、`!=`、`<>`、`<`、`<=`、`>`、`>=` | 相等与大小比较；`<>` 等同 `!=`。 |
| 5 | `and`、`&&` | 逻辑与，短路求值。 |
| 6，最低 | `or`、`||` | 逻辑或，短路求值。 |

`and`、`or`、`not`、`mod` 不区分大小写。`=` 用于赋值，**相等比较要写 `==`**。

### 运算时的类型规则

- `+` 只接受两个数字、两个字符串或两个列表；列表相加表示连接。`-`、`*`、`/`、`mod` 和一元正负号要求数字。除以零和模零都会报错。
- `<`、`<=`、`>`、`>=` 要求两边都是数字，或两边都是字符串。
- `==`、`!=` 可以比较任意值；列表按元素递归比较。树节点按对象身份比较，**不会按树的结构递归比较**。`leaf` 是同一个共享树叶值。
- 逻辑运算结果是布尔值。`false`、`0`、空字符串 `""`、空列表 `[]`、`null` 为假；其他值为真，包括树。

## 5. 内置函数

内置函数名不区分大小写。参数个数或类型不符会在运行时报错。内置函数优先于同名的自定义算法。

| 函数 | 返回值 |
| --- | --- |
| `value(list)` | 列表第一个元素；空列表返回 `null`。 |
| `tail(list)` | 去掉第一个元素后的新列表；空列表仍返回空列表。 |
| `cons(item, list)` | 把 `item` 放到列表开头，返回新列表。 |
| `isEmpty(list)` | 列表是否为空。 |
| `length(list)`、`length(string)` | 列表或字符串的长度。 |
| `node(left, root, right)` | 构造一个非叶子树节点。 |
| `left(tree)`、`root(tree)`、`right(tree)` | 取得树节点对应位置的值；对 `leaf` 调用时返回 `null`。 |
| `isLeaf(tree)` | 判断树值是否为 `leaf`。 |
| `abs(number)` | 绝对值。 |
| `min(a, b, ...)`、`max(a, b, ...)` | 至少一个数字，返回最小值或最大值。 |

这里的 `left`、`root`、`right` 是字段的名称，不表示 `node` 的三个参数必须是树；解释器允许树节点存放任意支持的值。

## 6. 运行入口与限制

运行配置必须是一次函数调用，例如 `F(10)`；也接受 `output=F(10)` 形式。默认运行入口是文件中的**第一个**算法。调用支持递归，参数表达式先求值，再进入被调用算法。

```text
Algorithm: SumTo(n)
  let total = 0
  while n > 0
    total = total + n
    n = n - 1
  endwhile
  print total
  return total
```

上例的运行配置是 `SumTo(5)`，`print` 输出 `15`，返回值也是 `15`。解释器默认最多执行 100,000 个计数步骤、调用深度最多 200 层；超限会报运行错误。语法检查报告当前解析到的第一个错误，运行时的变量未定义、参数不匹配和类型错误需实际运行后才能发现。

当前不支持列表下标访问（如 `a[0]`）、对象字段访问、`for` 循环、函数作为值、指数运算、字符串插值，以及用 `=` 比较相等。
